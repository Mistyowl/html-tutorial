Знакомство с CSS

HTML задаёт структуру страницы. CSS отвечает за внешний вид: цвета, отступы, шрифты, расположение блоков. Ниже — теория с живыми примерами и четыре практических задания.

1. Что такое CSS и зачем он нужен

CSS (Cascading Style Sheets) — язык стилей. Он говорит браузеру: «этот заголовок синий», «у кнопки скруглённые углы», «меню в один ряд».

Аналогия

Вспомни дом из урока HTML. HTML — стены и комнаты. CSS — обои, цвет стен, мебель и освещение. Без CSS страница работает, но выглядит «голой».

Три способа подключить стили

  1. Атрибут style="" прямо на теге — удобно для быстрой пробы, плохо для большой страницы.
  2. Тег <style> в <head> — стили на одной странице.
  3. Файл .css и тег <link> — лучший способ: один файл на много страниц.
Код 
<link rel="stylesheet" href="styles.css">
Как выглядит

Эта строка в <head> подключает внешний файл стилей. Так сделано на этой учебной странице.

Почему лучше <link>

Стили в одном месте: поменял цвет кнопки в файле — обновились все страницы. HTML остаётся чистым и читаемым.

Комментарии в CSS

Всё между /* и */ браузер игнорирует. В заготовках заданий такие комментарии подсказывают, что писать:

Код 
/* TODO: сделай фон белым */
.card {
  /* background: #fff; */
}
Как выглядит

Комментарии на экране не видны — они только для человека в коде.

2. Как устроено правило CSS

Правило состоит из селектора (кого красим) и объявлений в фигурных скобках (как красим).

Код 
p {
  color: #6750a4;
  font-size: 1.1rem;
}
<p>Этот абзац окрашен правилом CSS.</p>
Как выглядит

Этот абзац окрашен правилом CSS.

  • p — селектор (все абзацы)
  • color и font-size — свойства
  • #6750a4 и 1.1rem — значения
  • После каждого свойства ставят ;
Аналогия

Селектор — адрес: «всем абзацам». Фигурные скобки — инструкция внутри конверта. Свойство и значение — «сделай так: цвет фиолетовый».

3. DevTools: учимся подсматривать

В браузере можно «заглянуть» в стили любого сайта. Это не магия — обычный инструмент разработчика. Пользуйся им уже сейчас, на каждом примере.

  1. Открой страницу и нажми F12 (или ПКМ → «Просмотреть код»).
  2. Вкладка Elements / «Элементы» — дерево HTML.
  3. Справа Styles — какие правила действуют на выбранный элемент.
  4. Вкладка Computed показывает итоговые размеры и схему блочной модели (margin → border → padding → content).
  5. Кликни значение цвета или размера и поменяй — сразу видно эффект.
  6. Иконка курсора в углу панели позволяет ткнуть элемент на странице.
Зачем это на уроке

Когда копируете шапку красивого сайта — смотрите в DevTools: цвет фона, отступы, шрифт. Потом повторяете своими словами в CSS, а не копируете чужой код целиком.

4. Селекторы: кого выбираем

Чаще всего стили вешают не на все теги сразу, а на элементы с классом. Класс в HTML — атрибут class, в CSS перед именем пишут точку.

Код 
.note {
  color: #7d5260;
  background: #ffd8e4;
  padding: 0.5rem;
}
<p class="note">Подсказка</p>
Как выглядит

Подсказка

Основные виды

  • p — все теги <p>
  • .note — все с классом note
  • #logo — один элемент с id="logo"
  • * — любой элемент (часто в сбросе: *, *::before, *::after)
  • h1, h2, h3 — группировка через запятую: одно правило на несколько селекторов
  • nav a — ссылки внутри меню
  • button:hover — кнопка, когда навели мышь

На одном элементе может быть несколько классов: <button class="btn btn--primary">. В заготовках часто пишут имена вида card__title (блок card, элемент title) — так проще читать код.

Кто сильнее

Если два правила спорят, побеждает более «точное»: класс сильнее тега, id сильнее класса. Если сила одинаковая — побеждает то, что написано ниже в файле (каскад). Для учёбы почти всегда хватает классов.

Наследование

Часть свойств дети получают от родителя сами: color, font-family, font-size, line-height. Отступы, рамки и фон не наследуются.

  • font-family: inherit — взять шрифт у родителя (удобно для кнопок)
  • У браузера есть свои отступы у body — часто пишут body { margin: 0; }, чтобы начать «с чистого листа»

5. Цвета и единицы измерения

Цвет можно задать по-разному. Для уроков удобны hex и названия.

Код 
.swatch-red { background: red; }
.swatch-hex { background: #6750a4; }
.swatch-rgb { background: rgb(103, 80, 164); }
.swatch-rgba { background: rgba(103, 80, 164, 0.4); }
<div class="swatch-red">red</div>
<div class="swatch-hex">#6750a4</div>
<div class="swatch-rgb">rgb()</div>
<div class="swatch-rgba">rgba()</div>
Как выглядит
red
#6750a4
rgb()
rgba()

rgba() — как rgb(), но с четвёртым числом: прозрачность от 0 (невидимо) до 1 (непрозрачно). Так делают мягкие тени: rgba(0, 0, 0, 0.12).

Единицы размера: px, em, rem

Пока достаточно трёх единиц для текста и отступов. Проценты (%) появятся чуть позже — после блочной модели, когда станет ясно, кто «родитель», а кто «ребёнок».

px — пиксели

Самая простая единица: «столько-то точек на экране». 16px — обычный размер текста в браузере. Удобно, но если пользователь увеличит шрифт в настройках, жёсткие px иногда ведут себя хуже, чем rem.

em — «относительно шрифта рядом»

Буква em исторически означала ширину буквы «M». В CSS 1em = текущий размер шрифта этого элемента (для свойства font-size — размер шрифта родителя).

  • У абзаца шрифт 20px → padding: 1em даст отступ 20px
  • Если внутри поставить font-size: 0.5em, шрифт станет вдвое меньше родителя
  • Минус: при глубокой вложенности em «накапливаются» и легко запутаться
Код 
.box {
  font-size: 20px;
  padding: 1em; /* = 20px */
}
.box small {
  font-size: 0.75em; /* 75% от 20px = 15px */
}
<div class="box">
  Обычный текст
  <small>Мельче</small>
</div>
Как выглядит
Обычный текст Мельче (0.75em)
Аналогия

em — как шаги относительно своего роста: у высокого человека «один шаг» длиннее, у низкого — короче. Если внутри ещё кто-то помельче, его шаги считаются уже от него.

rem — «относительно корня страницы»

rem = root em. Считается всегда от размера шрифта у корня документа — тега html. В браузере по умолчанию это обычно 16px.

  • 1rem ≈ 16px
  • 2rem ≈ 32px
  • 0.5rem ≈ 8px

В отличие от em, вложенность не меняет расчёт: хоть внутри десяти коробок, 1.5rem везде одно и то же (пока не меняли шрифт у html).

Код 
/* У html по умолчанию ≈ 16px — в px не фиксируем */

.title {
  font-size: 2rem; /* ≈ 32px */
  margin-bottom: 1rem; /* ≈ 16px */
}
<h2 class="title">Заголовок</h2>
Как выглядит

Заголовок 2rem

Обычно пишут размеры текста и отступы в rem — так проще держать всю страницу в одном ритме.

Что брать на уроке

Для текста и отступов почти всегда бери rem. px — когда нужен совсем фиксированный размер (тонкая рамка 1px, иконка). em — реже, когда отступ должен расти вместе с шрифтом именно этого блока.

48px
3rem
2em

Полоски выше: слева фиксированные 48px, посередине 3rem (≈ 48px от корня), справа 2em при шрифте 12px — уже ≈ 24px, потому что считается от «местного» шрифта.

6. Текст и шрифты

Частые свойства для текста:

  • font-family — семейство шрифта
  • font-size — размер
  • font-weight — толщина (400, 700, bold)
  • line-height — высота строки
  • text-align — выравнивание: left, center, right
  • color — цвет текста
  • text-decoration — none (убрать подчёркивание у ссылки), line-through (зачеркнуть старую цену)
  • letter-spacing — расстояние между буквами
Код 
h1 {
  font-family: Roboto, sans-serif;
  font-size: 2rem;
  font-weight: 400;
  text-align: center;
  color: #21005d;
}
<h1>Заголовок</h1>
Как выглядит

Заголовок

Google Fonts

Красивые шрифты подключают ссылкой в <head> (как Roboto на этой странице), а потом указывают в font-family. Всегда добавляй запасной шрифт: sans-serif или serif.

7. Блочная модель: margin, border, padding

Каждый элемент — прямоугольник. Снаружи внутрь: margin (отступ снаружи) → border (рамка) → padding (отступ внутри) → содержимое.

Аналогия

Картина на стене: margin — расстояние до соседних картин, border — рама, padding — пустое поле вокруг холста, content — сама картина.

margin
border
padding
content
Код 
.card {
  width: 200px;
  padding: 16px;
  border: 2px solid #cac4d0;
  margin: 12px;
  box-sizing: border-box;
}
<div class="card">
  Карточка с отступами
</div>
Как выглядит
Карточка с отступами
Важно

Пиши box-sizing: border-box; (часто на все элементы). Тогда width включает padding и border — ширину проще считать.

Сокращённая запись

  • padding: 1rem; — со всех сторон
  • padding: 1rem 2rem; — сверху/снизу, слева/справа
  • padding: 1rem 2rem 0.5rem; — сверху, слева/справа, снизу
  • padding: 1rem 2rem 0.5rem 0; — сверху, справа, снизу, слева (по часовой)

То же работает для margin.

max-width, центрирование и overflow

  • max-width: 22rem; — «не шире этого»; удобно для карточек форм
  • margin: 0 auto; — центрирует блок по горизонтали (нужна заданная ширина или max-width)
  • overflow: hidden; — обрезает содержимое за краями; часто ставят на карточку со скруглением, чтобы картинка не «торчала»

Родитель, ребёнок и проценты (%)

В HTML теги вкладывают друг в друга. Внешний блок — родитель, то, что внутри — ребёнок (дочерний элемент).

Код 
<div class="parent">
  <div class="child">Я ребёнок</div>
</div>
.parent {
  width: 300px;
  background: #e8def8;
  padding: 12px;
}
.child {
  width: 50%; /* половина ширины родителя */
  background: #6750a4;
  color: #fff;
  padding: 8px;
}
Как выглядит
Я ребёнок · 50%

width: 50% у ребёнка — это «половина ширины родителя», не половина экрана. Если родитель шириной 300px, ребёнок ≈ 150px.

Ещё позже

vw / vh — проценты от окна браузера (viewport). Пригодятся для экрана во всю высоту: min-height: 100vh в форме входа.

9. Свойство display

Оно решает, как элемент ведёт себя в потоке страницы.

  • block — на всю ширину, с новой строки (div, p)
  • inline — в строке, без своей ширины/высоты (span, a)
  • inline-block — в строке, но можно задать ширину и отступы
  • none — спрятать элемент
  • flex / grid — современные раскладки (следующий раздел)
Код 
.as-block { display: block; }
.as-inline { display: inline; }
.as-inline-block { display: inline-block; }
<!-- block -->
<span class="as-block">A</span>
<span class="as-block">B</span>

<!-- inline -->
<span class="as-inline">A</span>
<span class="as-inline">B</span>

<!-- inline-block -->
<span class="as-inline-block">A</span>
<span class="as-inline-block">B</span>

10. Flexbox — главный помощник вёрстки

На контейнер ставят display: flex — дети выстраиваются в ряд (или колонку). Так делают шапки, строки цены и кнопки.

  • justify-content — вдоль главной оси (горизонталь по умолчанию)
  • align-items — поперёк оси (вертикаль)
  • gap — промежуток между элементами
  • flex: 1 — «растянись и займи свободное место»
  • flex-direction: column — столбиком
  • flex-wrap: wrap — перенос на новую строку, если не влезает
  • margin-left: auto — «отодвинь меня вправо» (часто для блока ссылок в шапке)
  • flex-shrink: 0 — «не сжимай меня»
  • order и flex-basis — порядок и базовая ширина (пригодятся в адаптивной шапке)
Код 
.row {
  display: flex;
  align-items: center;
  gap: 0.5rem;
}
.search {
  flex: 1; /* растяни поиск */
}
.actions {
  margin-left: auto; /* ссылки вправо */
}
<div class="row">
  <div>Лого</div>
  <div class="search">Поиск</div>
  <div class="actions">Корзина</div>
</div>
Как выглядит
Лого
Поиск
Корзина
Центр экрана

Чтобы поставить карточку по центру окна: min-height: 100vh; display: flex; justify-content: center; align-items: center; на родителе. Пригодится в форме входа.

11. Grid — сетка колонок

Flex удобен для одной строки или столбца. Grid — когда нужна таблица из ячеек: карточки преимуществ, галерея.

Код 
.grid {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
  gap: 0.5rem;
}
<div class="grid">
  <div>1</div>
  <div>2</div>
  <div>3</div>
</div>
Как выглядит
1
2
3

1fr — «одна доля свободного места». Три колонки по 1fr — равные по ширине.

12. Позиционирование

  • static — обычное поведение (по умолчанию)
  • relative — сдвиг относительно себя; якорь для absolute-детей
  • absolute — привязка к ближайшему спозиционированному предку (relative, absolute, fixed или sticky). Если такого нет — к странице
  • sticky — «липнет» при прокрутке. Нужен ещё top: 0 (или другое значение), иначе эффекта не будет
  • fixed — всегда на экране относительно окна
  • z-index — кто выше при наложении (больше число — ближе к зрителю)
Код 
.card { position: relative; }
.badge {
  position: absolute;
  top: 8px;
  left: 8px;
}
<div class="card">
  <span class="badge">−20%</span>
</div>
Как выглядит
−20%

13. Адаптивность: медиазапросы

На телефоне три колонки не помещаются. Медиазапрос меняет стили при определённой ширине окна. Не забудь <meta name="viewport" …> в HTML (см. урок HTML) — без него телефон «прикинется» широким экраном.

Код 
.grid {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
}

@media (max-width: 600px) {
  .grid {
    grid-template-columns: 1fr;
  }
}
<div class="grid">
  <div>1</div>
  <div>2</div>
  <div>3</div>
</div>
Как выглядит

Сузь окно браузера уже 600px — сетка из трёх колонок (класс .demo-grid) станет одной колонкой.

Два подхода

  • @media (max-width: …) — стили для экрана уже указанной ширины (сначала десктоп, потом упрощаем)
  • @media (min-width: …) — стили для экрана шире (сначала мобильная версия, потом добавляем колонки). Так часто пишут лендинги
Код 
.features {
  display: grid;
  grid-template-columns: 1fr; /* телефон */
}

@media (min-width: 700px) {
  .features {
    grid-template-columns: repeat(3, 1fr); /* шире */
  }
}
<div class="features">…</div>
Как выглядит

Базовые стили — для узкого экрана. Медиазапрос с min-width «включает» три колонки только на широком.

Картинки

Добавляй картинкам max-width: 100%; height: auto; — они не вылезут за край экрана.

14. Переходы и состояния

:hover — навели мышь, :focus — фокус с клавиатуры (важно для полей формы). :focus-visible — обводка только когда фокус с клавиатуры (удобнее для мыши). transition делает смену плавной.

  • cursor: pointer — рука над кликабельным элементом
  • outline — обводка фокуса. Не убирай outline: none без своей заметной замены (рамка или тень)
  • transform: translateY(-1px) — лёгкий сдвиг при наведении
Код 
.btn {
  background: #6750a4;
  cursor: pointer;
  transition: background 0.2s ease, transform 0.15s ease;
}
.btn:hover {
  background: #5a4590;
  transform: translateY(-1px);
}
.btn:focus-visible {
  outline: 2px solid #6750a4;
  outline-offset: 2px;
}
<button class="btn" type="button">
  Наведи на меня
</button>
Как выглядит

15. Чеклист: как писать CSS

  • Стили в отдельном файле или в <style>, а не в куче style=""
  • Используй классы: class="card" → .card { … }
  • После свойства ставь точку с запятой
  • Включи box-sizing: border-box
  • Для рядов — Flex, для сеток карточек — Grid
  • Картинки: max-width: 100%
  • Проверь страницу на узком экране (или сузь окно)
  • Кнопки и поля имеют заметный :hover / :focus-visible
  • Не убирай outline без своей замены

16. Практика: четыре задания
